# Rule: Agent Skills Enforcement

1. Before generating frontend code, layouts, animations, or UI critiques, search `.agents/skills/` for relevant skills.
2. If a relevant skill is found, read its `SKILL.md` and strictly apply its principles, design tokens, and best practices.
3. Avoid generic placeholder designs; apply modern aesthetic standards, tactile micro-interactions, and appropriate cognitive heuristics (e.g. Fitts's Law, Jakob's Law, aesthetic-usability effect).
